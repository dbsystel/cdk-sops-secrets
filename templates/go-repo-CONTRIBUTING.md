# Contributing

This repository contains **only** the automatically generated Go bindings for
[`cdk-sops-secrets`](https://github.com/dbsystel/cdk-sops-secrets). It is not
developed here and does not accept contributions directly.

Please contribute in the source repository instead:

- **Contribution guide:** https://github.com/dbsystel/cdk-sops-secrets/blob/main/CONTRIBUTING.md
- **Issues & bug reports:** https://github.com/dbsystel/cdk-sops-secrets/issues
- **Pull requests:** https://github.com/dbsystel/cdk-sops-secrets/pulls

Any change committed directly to this repository will be overwritten by the
next release.
